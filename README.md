## Portfolio Optimization: Communication Services Sector


This project builds an optimal long-only portfolio using Modern Portfolio Theory.

Features

- Downloads S&P500 data automatically
- Computes daily returns
- Estimates expected returns from analyst targets
- Computes covariance matrix
- Maximizes Sharpe Ratio
- Compares with SPY benchmark
